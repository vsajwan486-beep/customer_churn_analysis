
# Customer Churn Analysis

## Overview
An exploratory data analysis project that investigates customer churn
patterns using the IBM Telco Customer Churn dataset.

## Business Objective
Understand which customer groups show higher churn rates and identify
patterns that could inform customer retention strategies.

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and quality checks
- Overall churn rate calculation
- Churn analysis by contract type and payment method
- Tenure and monthly charge comparisons
- Data visualization and business interpretation

## Key Findings
See project_report.md for the verified findings and conclusions.

## Project Structure
- data/: processed data
- notebooks/: analysis notebooks
- images/: exported charts
- project_report.md: detailed findings and limitations

## How to Run
1. Clone or download this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using:
   pip install -r requirements.txt
4. Open Jupyter Notebook.
5. Run the project notebooks in the documented order.

## Limitations
The analysis is exploratory. Associations do not establish causation,
and the findings should not automatically be generalized to every business.
